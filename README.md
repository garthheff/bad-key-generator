# Private Key Generator. a parody

Open `index.html` in any modern browser. No installation, build step, internet connection, or server is required. You can also upload it to any static web host.

The complete website is one self-contained HTML file, including CSS and JavaScript. It uses system fonts, an inline SVG, and no dependencies, remote assets, backend, analytics, cookies, or persistent storage.

The generator selects only from **4, 56, 66, 115, 155, 156, 230, 237** using `Math.random()`. Repeated values are intentional. The initial value is 4. The copy button copies only the displayed number; browsers that restrict clipboard access (including some local-file contexts) show instructions to copy it manually.

**This is a joke. It is not cryptographically secure. Never use any generated value for real cryptographic keys.** It does not create key files or certificates. The bureau is fictional and the security-rating punchlines refer to documented historical incidents. Expand “Security-rating jokes: the receipts” for context and primary-source links. Ratings cycle independently of the generated number; they are satire, not real security assessments.

Features include responsive layouts, keyboard-accessible controls, visible focus outlines, an announced result/status, reduced-motion support, and a JavaScript-disabled notice.

The action button reads “Generate another bad key”. Eight rotating ratings include SolarWinds, Uber, Facebook, and fictional security mishaps. Source links are ordinary optional links; nothing external loads automatically.

“Why this is terrible” explains the eight-value guessing problem, insecure randomness, and the consequences of guessable signing keys, with a responsive three-column layout.
